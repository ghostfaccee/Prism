Prism

Единый API вместо десятка интеграций. Экономьте часы разработки на том, что уже сделано.

Начать Изучить API
bash 
$ curl -X GET http://127.0.0.1:8001/v1/
{ 
  "detail" : "Welcome to Prism :)" 
}
Почему Prism?

Всего один слой
между вами и данными.

Prism берёт на себя интеграцию с внешними сервисами, jwt-авторизацию, кеширование, ограничение запросов и другую чепуху - чтобы ваше приложение работало.

Единый API

REST-like интерфейс вместо отдельных интеграций.

Async first

Асинхронность "из коробки" и удобная работа с внешними сервисами.

"Батарейки в комплекте"

Ничего настраивать не надо. Всю рутину Prism берёт на себя.

Quickstart

От нуля
до API за минуты.

Скачайте Prism, установите зависимости и запустите локальный сервер.

Документация →
bash 
$ git clone https://github.com/ghostfaccee/Prism.git
$ cd Prism
$ docker compose --profile prod up --build -d
$ docker compose exec api alembic upgrade head
Prism

с каждым днём.
