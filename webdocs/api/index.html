API Reference

Prism - API для сбора данных из внешних источников и не только. Здесь описаны все эндпоинты на данный момент (16.08.2026 - Prism v1.0).

⚠️ Важно: Ответы GitHub API в примерах могут быть ошибочными. Рекомендую сверяться с официальной документацией GitHub REST API, если вам важна точность и конкретность.

Главная

Тип запроса: GET

Путь: /v1/

Авторизация: не требует

Статус-код: 200 OK

Описание: простая заглушка, которая всегда возвращает сообщение

Формат входных данных: отсутствует

Формат выходных данных: json

// json
{
  "detail" : "message"
}

Регистрация

Тип запроса: POST

Путь: /v1/auth/register

Авторизация: не требует

Статус-код: 201 CREATED

Описание: создаёт нового пользователя

Формат входных данных: json

// json
{
    "username" : "your username (required)",
    "password" : "your password (required)",
    "email" : "your email (optional)"
}

Формат выходных данных: json

// json
{
  "user_id": "your uuid",
  "username": "your username",
  "email": "your email",
  "is_active": true/false
}

Вход

Тип запроса: POST

Путь: /v1/auth/login

Авторизация: не требует

Статус-код: 200 OK

Описание: вход в аккаунт

Формат входных данных: json

// json
{
    "username" : "your username (required)",
    "password" : "your password (required)"
}

Формат выходных данных: json

// json
{
    "access_token": "access token",
    "refresh_token": "refresh token",
    "token_type": "token type",
    "access_token_expires_in_minutes": minutes,
    "refresh_token_expires_in_days": days
}

Выход

Тип запроса: POST

Путь: /v1/auth/logout

Авторизация: требует jwt-токен в заголовке (см. раздел "Аутентификация" в документации)

Статус-код: 204 NO CONTENT

Описание: выход из аккаунта

Формат входных данных: отсутствует

Формат выходных данных: отсутствует

    Подтверждение электронной почты

    Тип запроса: GET

    Путь: /v1/verify/{token}

    Параметры:

  • token - token пользователя

    • Авторизация: требует jwt-токен в заголовке (см. раздел "Аутентификация" в документации)

    Статус-код: 200 OK

    Описание: позволяет подтвердить электронную почту пользователя

    Подробнее: после того, как пользователь указал почту при регистрации или изменил её, на указанную почту отправится письмо со ссылкой, в которой находится сгенерированный токен. Этот токен уникальный и привязан к конкретному пользователю. После перехода по этой ссылке почта пользователя считается подтверждённой, и поле is_active, указывающее, активирован ли пользователь, становится true.

    Формат входных данных: отсутствует

    Формат выходных данных: json

    // json
{
  "detail" : "message"
}

    GitHub oauth

    Тип запроса: GET

    Путь: /v1/github/login

    Авторизация: требует jwt-токен в заголовке (см. раздел "Аутентификация" в документации)

    Статус-код: 307 TEMPORARY REDIRECT

    Описание: перенаправляет пользователя на страницу аутентификации GitHub

    Подробнее: создаёт state для защиты от csrf-атак и перенаправляет пользователя по созданной ссылке. После аутентификации по этой ссылке GitHub перенаправит пользователя на эндпоинт /v1/github/callback

    Формат входных данных: отсутствует

    Формат выходных данных: отсутствует

    GitHub callback

    Тип запроса: GET

    Путь: /v1/github/callback

    Авторизация: требует jwt-токен в заголовке (см. раздел "Аутентификация" в документации)

    Статус-код: 200 OK

    Описание: эндпоинт, на который GitHub перенаправляет пользователя после аутентификации

    Подробнее: в параметрах запроса будут переданы code и state. Code - краткоживущий код, который Prism обменивает на access_token для дальнейшего использования. Этот access_token используется для запросов к GitHub API. State - код, который генерируется ещё в эндпоинте /v1/github/login и используется для защиты от csrf-атак.

    Формат входных данных: отсутствует

    Формат выходных данных: json

    // json
{
    "access_token" : "token",
    "token_type" : "token type",
    "scope": "scope"
}
